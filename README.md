# bcpg-fips 1.0.7.1 (source baseline)

Unmodified sources of `org.bouncycastle:bcpg-fips:1.0.7.1` from the official
`bcpg-fips-1.0.7.1-sources.jar` on Maven Central. Bouncy Castle publishes no git tag for the FIPS line.
`pom.xml` is a reconstructed build recipe (Java 5 bytecode, `-g:none`, original manifest). The jar it builds is
instruction-identical to the public `bcpg-fips-1.0.7.1.jar` (`javap -c` over every class).
`src/main/resources/module-info.class` is copied verbatim from the public jar, because the sources jar omits `module-info.java`.
Used by Seal Security as the upstream reference for sealed (patched) builds.
